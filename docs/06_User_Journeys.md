# User Journeys

## Owner: vet booking
1. Open app → location permission explanation (or choose city/area manually).
2. Home → “Book a vet”.
3. Select pet → search service and provider.
4. Compare verified clinic/doctor, distance, service, price and availability.
5. Select service/date/time → add symptoms/context (non-diagnostic prompt).
6. Review booking policy → confirm with mock payment.
7. Booking detail and notification.
8. Visit → provider marks completed → owner review.

## Owner: caretaker request
1. Select pet(s) → “Find a caretaker”.
2. Choose service type, dates, location, care requirements and optional budget.
3. Submit request.
4. Receive offers → compare provider, verification, experience, price, capacity and reviews.
5. Contact via booking-context messaging in later phase; MVP can use structured questions/offer notes.
6. Select offer → confirm mock payment and booking.
7. Meet-and-greet/check-in → care updates (Phase 2) → completion → review.

## Caretaker: responding to request
1. Provider profile/onboarding → identity and required checks.
2. Set services, service radius, availability, rates and capacity.
3. Browse matching requests or receive notifications.
4. Submit quote with availability, price and details.
5. If selected, confirm booking, view pet care notes (permission-scoped), manage status.
6. Complete care and receive review/payout status.

## Clinic: appointment management
1. Create clinic profile and location.
2. Add doctors, credentials and services.
3. Set hours, appointment durations, capacity, breaks and blackout dates.
4. Verify listing.
5. Receive booking; confirm/manage/reschedule/cancel.
6. Mark visit completed; manage follow-up note (only if owner consent and suitable privacy controls).

## Community: local post
1. Select local feed and location scope.
2. Create text/photo post and optionally attach pet.
3. Feed displays content with privacy and moderation controls.
4. Like/comment/report/block.
5. Moderation action is logged; author receives appropriate notice.

## Admin: verify provider
1. Verification queue.
2. Review identity, credentials/registration where relevant, business and documents.
3. Approve, reject with reason or request more information.
4. Set verification badges/limits.
5. Audit action and monitor reports.
